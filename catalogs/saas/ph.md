## uplb.tools

| Field | Value |
|-------|-------|
| URL | https://www.uplb.tools/ |
| Cost | free forever |
| Student | student helps |
| Commercial | commercial ok |
| Limits | Free web tools · not an official UP site |
| Tags | campus |
| Verified | 2026-07-24 |

UPLB campus utilities — rooms, gradesim, housing links. Privacy-first.

**Pick this if** you're a UPLB student and want one bookmark for rooms, grades, and housing instead of juggling SAIS, Facebook groups, and outdated PDFs. It's the unofficial campus Swiss-army knife.

**vs official UP SAIS:** uplb.tools is faster, mobile-friendly, and adds features SAIS doesn't (grade simulation, route maps). SAIS is authoritative for enrollment; uplb.tools is authoritative for everything else.

**Pick this if** you regularly need to find which building a class is in, check jeepney schedules, or plan routes — especially when campus Wi-Fi is spotty. The PWA works offline, which is the killer feature.
