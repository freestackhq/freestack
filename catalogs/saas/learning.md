## Frontend Masters (Pack)

| Field | Value |
|-------|-------|
| URL | https://frontendmasters.com |
| Cost | student free |
| Student | student required |
| Commercial | commercial ok |
| Limits | 6 months via Pack |

Deep frontend and systems courses.

**Pick this if** you want to mass-level frontend skills (React, TypeScript, performance) or go deep on systems (Rust, compilers, networking) with video courses taught by actual library authors — not random YouTubers.

**vs Udemy/Coursera:** FM is curated and opinionated — 200 courses from working engineers, not 200k courses of variable quality. No certificates, but real skill.
**vs Pluralsight:** FM's instructors ship frameworks you actually use (Webpack, Vite, Svelte). Pluralsight skews enterprise/.NET.

## Educative (Pack)

| Field | Value |
|-------|-------|
| URL | https://www.educative.io |
| Cost | student free |
| Student | student required |
| Commercial | commercial ok |
| Limits | 6 months · 30% off later |

Interactive courses — system design, interviews.

**Pick this if** you're grinding system design or coding interviews and prefer reading + in-browser coding over watching videos. The "Grokking" series lives here and it's genuinely the fastest path to FAANG-style system design fluency.

**vs LeetCode Premium:** Educative teaches patterns and mental models; LeetCode is pure drill. Use both — Educative first to learn the framework, then LeetCode to build speed.
**vs AlgoExpert:** Educative has broader coverage (system design, ML, cloud) and text-first format vs AlgoExpert's video-heavy approach.

## DataCamp (Pack)

| Field | Value |
|-------|-------|
| URL | https://www.datacamp.com |
| Cost | student free |
| Student | student required |
| Commercial | commercial ok |
| Limits | 3 months individual via Pack · other seats via vendor donate partners |

Data and ML course supplement.

**Pick this if** you need structured ramp-up on pandas, SQL, ML basics, or stats — and you learn best by doing exercises in a notebook-style environment rather than watching lectures. Great as a supplement alongside a CS degree, not a replacement.

**vs Kaggle Learn:** DataCamp has longer guided paths and career tracks; Kaggle Learn is micro-courses (2–4 hrs) best for quick refreshers. DataCamp wins on breadth, Kaggle on speed.
**vs Coursera ML Specialization:** Andrew Ng goes deeper on theory; DataCamp gets you writing sklearn/pandas code faster with less math preamble.

## Boot.dev (Pack)

| Field | Value |
|-------|-------|
| URL | https://www.boot.dev |
| Cost | student free |
| Student | student required |
| Commercial | commercial ok |
| Limits | 3 months full membership |

Backend / DevOps learning path.

**Pick this if** you want a gamified, opinionated backend path (Go, Python, SQL, Docker, CI/CD) that feels like a game with XP and streaks — and you specifically want backend/infra skills, not frontend. The curriculum is tight and builds toward "deploy a real service" not "pass a quiz."

**vs The Odin Project:** Boot.dev is structured and gamified with a single language path; Odin is community-driven, broader (full-stack), and free forever but requires more self-direction.
**vs freeCodeCamp:** Boot.dev focuses on backend/systems (Go, algorithms, Linux); freeCodeCamp is frontend-heavy (HTML/CSS/JS/React) with backend as an afterthought.
