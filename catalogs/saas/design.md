## Figma Education

| Field | Value |
|-------|-------|
| URL | https://www.figma.com/education/apply |
| Cost | student free |
| Student | student required |
| Commercial | edu only |
| Limits | Yearly reapply · edu-only · K-12 gets Enterprise |
| Tags | must-claim |

Professional plan free for higher-ed students.

**Pick this if** you need unlimited projects, shared team libraries, and branching — the full Professional feature set — without paying $15/seat/mo. You're enrolled in higher-ed and can re-verify yearly.

**vs Figma Starter:** Starter caps you at 3 Figma files and 3 FigJam files per team; Education unlocks unlimited files, shared libraries, and dev-mode — the tools you actually need for group capstone work.

| Field | Value |
|-------|-------|
| URL | https://www.figma.com |
| Cost | free forever |
| Student | anyone |
| Commercial | commercial ok |
| Limits | Starter plan caps |

Anyone can design with free Starter limits.

**Pick this if** you're not a student (or can't be bothered with yearly verification) and just need a real vector/UI tool for side projects. Three files is plenty for a portfolio site, a mobile mockup, and a playground.

**vs Figma Education:** Education gives you unlimited files and team libraries, but locks usage to non-commercial. Starter lets you ship commercial work — just with fewer files open at once.

## Autodesk Education

| Field | Value |
|-------|-------|
| URL | https://www.autodesk.com/education |
| Cost | student free |
| Student | student required |
| Commercial | edu only |
| Limits | 1-year renewable · non-commercial |

AutoCAD, Fusion 360, Maya, Revit — renewable yearly.

**Pick this if** your coursework requires parametric CAD (mechanical parts in Fusion 360), architectural BIM (Revit), or film-grade 3D animation (Maya). These are industry-standard desktop apps with no browser equivalent.

**vs Blender:** Blender covers organic modeling and animation for free, but lacks parametric CAD constraints and BIM workflows. If your professor specifies Revit drawings or STEP exports, Autodesk is the only free path.

| URL | https://www.adobe.com/creativecloud/plans.html |
| Cost | discount |
| Student | student required |
| Commercial | check ToS |
| Limits | ~60% off retail |

All Apps cheaper — still a subscription.

**Pick this if** your workflow demands Photoshop, Premiere, or After Effects specifically — because your team shares .psd/.aep files, or an internship requires Adobe deliverables. The discount makes the ~$23/mo sting less, but it still stings.

**vs Figma + DaVinci Resolve:** For UI design + video editing alone, Figma (free) plus DaVinci Resolve (free) covers 80% of use cases at $0. Adobe only wins when you need the exact Adobe file format or a tool like Illustrator's print-press output.

## Godot

| Field | Value |
|-------|-------|
| URL | https://godotengine.org |
| Cost | free forever |
| Student | anyone |
| Commercial | commercial ok |
| Limits | Fully free / open source |

Open-source game engine. No student ID needed.

**Pick this if** you want to build a 2D or 3D game and own every line of your engine. GDScript is beginner-friendly, the editor runs on potato hardware, and you can ship commercially on Steam/itch.io with zero royalties or fees.

**vs Unity/Unreal:** Unity charges a runtime fee past $200K revenue; Unreal takes 5% after $1M. Godot takes nothing, ever. Trade-off: fewer AAA-ready rendering features and a smaller asset marketplace — fine for indie and jam-scale games.

## Canva Education

| Field | Value |
|-------|-------|
| URL | https://www.canva.com/education/ |
| Cost | student free |
| Student | student required |
| Commercial | edu only |
| Limits | While verified edu · not a commercial design seat |
| Tags | edu |
| Verified | 2026-07-24 |

Canva Pro features free for verified students and teachers.

**Pick this if** you need quick social media graphics, slide decks, or print posters without learning Figma or Illustrator. The drag-and-drop template library is unmatched for non-designers who still want polished output.

**vs Figma Education:** Figma is a precision UI/UX tool for developers and designers building interfaces. Canva is a marketing/content tool for fast visual assets. If you're designing app screens, use Figma; if you're making an event flyer in 10 minutes, use Canva.
